# Responsive Design Standards — E-Cell MITAOE

## 1. Verified Breakpoints
- **Mobile Compact:** 390 × 844 (iPhone 14 / modern handhelds)
- **Mobile Large:** 430 × 932 (iPhone 15 Pro Max / large mobile)
- **Tablet Portrait:** 768 × 1024 (iPad Mini / standard tablet)
- **Tablet Landscape / Small Laptop:** 1024 × 768
- **Standard Desktop:** 1440 × 900
- **Wide Display:** 1920 × 1080

## 2. Responsive Motion Adaptations
- On touch devices, replace mouse hover/click-and-hold requirements with tap/scroll triggers.
- Automatically scale canvas radius and font sizes based on viewport dimensions.
- Zero horizontal overflow (`overflow-x: hidden`).
- Navigation automatically converts into an accessible full-screen/sheet mobile drawer.
