# E-Cell MITAOE Frontend Design Skill

Use this skill when implementing UI components, pages, or sections for the MITAOE Entrepreneurship Cell.

## Principles
- **Editorial Architectural Language:** Use bold geometric typography (Sora), clean body copy (Plus Jakarta Sans), and mechanical monospace metadata (IBM Plex Mono).
- **Blue-and-White Dominance:** Pure white surfaces `#FFFFFF` and pale blue `#F8FAFF` dominate, structured by tech electric blue `#155EEF` and deep navy `#101B32`.
- **Structured Storytelling:** Avoid repetitive rounded cards. Use alternating asymmetrical layouts, numbered index entries (001–010), and monospace coordinate annotations.
