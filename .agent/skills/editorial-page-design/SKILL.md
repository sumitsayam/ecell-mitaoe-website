# Editorial Page Design Skill

Use this skill when developing or refining individual routes within the E-Cell MITAOE ecosystem.

## Guidelines
- Inner pages must maintain the same typographic scale and blueprint grid styling as the homepage.
- Use SectionHeaders with numeric indexes (e.g. `008 // THE FOUNDER'S JOURNAL`).
- Provide breadcrumb back-links and share mechanisms on dynamic reading routes (`/events/[slug]`, `/initiatives/[slug]`, `/insights/[slug]`).
- Do not introduce conflicting color themes across pages.
